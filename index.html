Google Calendar Embed Codes

This page is the central reference for trainer calendars. In LearnWorlds, copy the standard template and only replace the trainer name, divId, and calendarId.

Template for LearnWorlds

<div id="YOUR_DIV_ID"></div>
<script>
  (function() {
    const userTimeZone = Intl.DateTimeFormat().resolvedOptions().timeZone;
    const calendarId = "YOUR_GOOGLE_CALENDAR_ID";

    const iframeSrc = `https://calendar.google.com/calendar/embed?src=${calendarId}&ctz=${encodeURIComponent(userTimeZone)}&mode=WEEK`;

    const iframe = document.createElement("iframe");
    iframe.src = iframeSrc;
    iframe.style.border = "0";
    iframe.width = "800";
    iframe.height = "600";

    document.getElementById("YOUR_DIV_ID").appendChild(iframe);
  })();
</script>
